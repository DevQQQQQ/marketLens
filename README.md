## 🌟 为什么选择 MarketLens？

作为程序员，在工作专注编码时，经常需要兼顾自选资产（基金、股票、指数、加密代币、链上新币）的盘面异动。频繁切换桌面炒股炒币软件不仅打断工作心流，而且容易被旁人察觉。

**MarketLens** 将全市场行情与效率预警深度融合进 VS Code 编辑器中：

- 🌲 **六合一全能行情**：场内ETF/基金、A股、港股、美股、Binance 主流币、Alpha 链上新币一站式聚合，告别多软件频繁切换；
- ⚡ **到价预警与波动监控**：突破上限、跌破下限、单日暴涨暴跌实时提醒，无需时刻盯盘，专注写代码；
- 🖱️ **多选批量拖拽排序**：支持键盘 `Shift` / `Ctrl`（Mac `Cmd`）选中多只标的，一次性批量拖动重排；
- 🕶️ **极致专注与安全隐秘**：配备老板键一键隐藏、终端日志伪装摸鱼、颜色脱敏模式、休市自动节流；
- 📊 **状态栏无缝轮播**：底部状态栏按需滚动行情，支持各板块独立开关精细控制；
- 🧹 **活跃集修剪与极低内存占用**：自动回收死缓存与内存对齐机制，常态增量堆内存仅数兆（Heap Used 稳定 < 15MB~25MB），持久挂机无泄漏；
- 🛡️ **网络安全**：境内正规源直连，Web3 接口强制走本地代理，杜绝公司网关留痕。

### 2. ⚡ 价格阈值与剧烈波动预警监控系统（极度刚需）

写代码时无需一直盯盘，当标的突破关键阻力位、跌破止损位或出现暴跌剧烈异动时，系统及时精准提醒：

- **三种灵活预警规则**：
    - **`突破上限预警 (高于目标价)`**：现价大于等于目标值时提醒（如茅台突破 1800、BTC 突破 75000）；
    - **`跌破下限预警 (低于目标价)`**：现价小于等于目标值时提醒（如茅台跌破 1500、SOL 跌破 110）；
    - **`单日剧烈波动预警 (涨跌幅突破)`**：日内涨跌幅绝对值超过阈值百分比时提醒（如单日涨跌超 10%）；
- **双通道智能提醒方式**：
    - **VS Code 右下角轻量通知**：轻量弹窗浮窗提示，支持快速关闭与操作；
    - **状态栏闪烁高亮**：底部状态栏静默高亮变色切换，绝不打扰代码思路；
    - **双通道协同**：通知弹窗与状态栏同时提醒。
- **15分钟防轰炸冷却机制（可自定义）**：
    - 同一标的触发报警后，内存自动拦截进入冷却静音期（默认 15 分钟，支持在设置中自定义 1~1440 分钟），防止关键价位反复小幅拉锯引发连续弹窗轰炸。
- **老板键一票否决静音守卫**：
    - 当通过老板键隐藏看板时，预警评估引擎自动启动全局静默守卫，一票否决全部弹窗通知，彻底杜绝摸鱼露馅风险。
- **标的常驻持久化 `🔔` 标记与气泡预览**：
    - 只要标的配置了有效的预警规则，侧边栏标的行右侧将**常驻显示 `🔔` 图标**；
    - 鼠标悬停在标的上即可在卡片气泡中实时预览当前生效的具体预警阈值。
- **图形化集中监控矩阵**：
    - 在 Webview 设置面板「⚡ 到价预警」中提供全局监控矩阵，支持集中查看全部板块自选标的、直接在表格中调整目标价数值与独立监控开关；
    - 侧边栏与设置面板 **0ms 双向实时同频**，在侧边栏添加、删除或拖拽标的，设置面板无需关闭重开即刻同步。

### 3. 💾 自选标的与配置一键导出与导入恢复（换机与分享神器）

- **📤 一键导出备份 (JSON)**：
    - 将当前全部自选标的（含基金/A股/港股/美股/Binance/Alpha）、自定义备注名、排序位置、到价预警规则及全局偏好设置导出为标准 JSON 备份文件；
    - 解决企业内网、离线环境无法使用云同步的痛点，支持历史组合备份与好友分享。
- **📥 一键导入恢复 (JSON)**：
    - 从本地备份文件秒级还原全部自选标的与设置，具备 Schema 数据校验与确认弹窗保护；
    - 写入后即时刷新自选列表、状态栏与设置面板，无需重启 VS Code。
- **🎮 双入口便捷操作**：
    - 支持 VS Code 命令面板（`MarketLens: 导出配置备份 (JSON)...` / `MarketLens: 导入配置恢复 (JSON)...`）与图形化设置中心按钮两种操作方式。

### 4. 🔀 灵活的标的置顶与多模式分组排序自由管理（支持多选批量重排）

- **多选批量拖拽排序**：
    - 支持按住键盘 `Shift`（连续多选）或 `Ctrl` / `Cmd`（离散多选）鼠标点击选中 3~5 个或任意数量标的；
    - 鼠标拖拽一次性批量移动至目标位置，保持所选标的的相对顺序；
    - **同组边界严格隔离**：内置板块边界守卫，严格限制仅在当前分组内调整顺序，彻底杜绝跨板块误拖拽；
    - **单次原子化写入**：一次操作仅触发一次磁盘持久化，消除高频 I/O 冲突。
- **一键置顶标的**：右键点击标的或通过命令选择 **🔝 置顶**，即可瞬间将核心关注标的移动至当前分组第一行；
- **快速设置预警与删除**：悬停点击 **`🔔` 预警** 按钮呼出设置向导；点击 **`🗑️` 删除** 图标安全移除单只标的；
- **一键清空自选标的**：在设置中心支持一键将所有默认预设标的置空，保留板块结构，方便从零自由建立属于自己的自选库；
- **一键恢复出厂预设**：随时一键重置回系统初始预设资产库，并同步清空重置所有价格预警规则。

### 5. 📊 底部状态栏平滑轮播系统

- **平滑无缝轮播**：数据刷新与轮播定时器解耦，杜绝每 5 秒数据更新造成的轮播重置与口吃现象；
- **全部标的参与轮播（总控开关）**：在【通用设置】中一键控制底部状态栏是否展示行情，关闭后状态栏彻底隐藏；
- **各板块独立轮播开关**：
    - 支持单独控制 `基金`、`A股`、`港股`、`美股`、`Binance`、`Alpha` 标的是否进入状态栏轮播；
    - 例如：可设置左侧看板查看全部资产，但底部状态栏仅循环播放你最关心的美股或币安代币。

### 6. 🕶️ 极致摸鱼与安全脱敏

- 🕶️ **老板键一键隐藏 / 恢复 (`Ctrl + Alt + M` / `Alt + M`)**：
    - 瞬间隐藏左侧自选看板、清空底部状态栏行情、关闭设置面板；
    - 再次按下快捷键，所有看板与状态栏立即恢复，响应毫秒级；
    - 主动重新打开自选看板（点击活动栏 MarketLens 图标）同样会自动退出专注模式，确保「简洁展示模式 (`Alt + K`)」等显示开关即时生效，不会被隐身状态持续覆盖；
    - **专注模式期间插件保持完全静默**：不弹出任何状态栏临时提示、通知与信息弹窗；设置面板因会完整列出全部自选标的名称，故在专注模式期间静默拒绝打开，杜绝任何回显自曝意图。
- 🎭 **伪装摸鱼模式 (`Ctrl + Alt + K` / `Alt + K`)**：
    - 将底部状态栏行情伪装成极度真实的编译日志或 Git 分支状态（例如：`git:(main) build: 65.2k`），路过者毫无察觉；
    - 同时作用于左侧自选列表：价格与涨跌幅同步替换为 `****` 遮罩，避免侧边栏露出真实盘面；
    - 专注模式激活期间按下 `Alt + K`，会先自动退出专注模式再关闭打码，确保显示开关永远不会被隐身状态静默覆盖。
- ⚪ **颜色脱敏模式 (`Ctrl + Alt + L` / `Alt + L`)**：
    - 一键关停刺眼的“红涨绿跌”或“绿涨红跌”视觉刺激；
    - 所有数值采用编辑器默认的中性前景色，低调优雅。
- 💤 **交易时段智能休眠节流**：
    - 各大市场休市与周末期间自动停止轮询，大幅减少 CPU 占用与无意义网络流量。

### 7. 🧹 内存活跃集对齐与动态垃圾回收（Active-Set Pruning）

- **只监控活跃自选，零内存泄漏**：
    - 随着自选标的的添加与频繁删除，传统插件容易在内存保留无用的历史行情缓存与定时器；
    - MarketLens 实现 **Active-Set Pruning（活跃集动态对齐）** 与活跃集修剪 + 死缓存回收机制；
    - 当删除或清空标的时，即刻主动回收已失效标的的内存行情镜像，防止内存占用随运行时间单调膨胀；
    - 结合垃圾回收策略，即便全天挂机 24 小时，插件宿主进程内存占用始终平稳保持在数兆（MB）级轻量水平。

#### 🔒 网络隐私与防护原理

1. **绝对零凭证与零数据上传**：
    - 插件**不需要任何 API Key、Token 或用户账号密码**；
    - 绝不收集、记录或上传用户的代码、工作区、设备指纹或自选标的列表，所有自选资产仅安全保存在本地 VS Code 的 `settings.json` 中。
2. **强制代理底层物理阻断（杜绝直连降级）**：
    - 当为特定板块（如 Binance、Alpha）开启【强制代理】后，网络层会严格仅向本地回环代理端口（如 `http://127.0.0.1:10808` 或 `7890`）投递数据包；
    - **绝对杜绝静默直连**：若代理客户端未启动或端口连不上，插件会主动熔断拦截并报错，**绝不会为了获取数据而偷偷退化为直连访问**；
    - **公司网关留痕防御**：目标域名解析（DNS）与 TLS 握手均在本地代理软件及代理节点内部完成，企业防火墙和网络审计设备只能观察到 VS Code 进程与本地环回地址（`127.0.0.1`）之间的通信，无法捕获到 `binance.com` 等敏感域名的 SNI 握手特征。
3. **一键代理自动探测与自适应探测池**：
    - 设置中心提供 `⚡ 探测代理` 按钮，自动识别本机常见代理端口（如 Clash `7890`/`7897`、v2rayN `10808`/`10809`、sing-box `2080` 等），一键配置零门槛；
    - 具备 30 秒全局探测冷却与熔断保护，代理离线时绝不引发请求风暴。
4. **交易时段休眠节流**：
    - 基金、A股、港股、美股在非交易时段及周末全自动停发轮询请求，进一步规避不必要的网络发包特征。

### 1. 添加自选资产

点击自选看板顶部的 **`+`** 按钮，输入框具备**智能多格式正则解析**：

- **添加基金 / 场内 ETF**：输入 6 位基金代码（如 `510050` 上证50ETF、`159915` 创业板ETF、`588000` 科创50ETF、`161725` 白酒LOF，或带前缀 `sh510050`、`sz159915`），智能识别并选择归入 `基金` 或 `A股` 分组；
- **添加 A 股**：输入 6 位数字（如 `600519` 贵州茅台，或带前缀 `sh600519`、`sz000001`），自动归入 `A股` 分组；
- **添加港股**：输入 5 位数字或带前缀（如 `00700` 腾讯控股、`hk03690` 美团），自动归入 `港股` 分组；
- **添加美股**：输入美股 Ticker（如 `AAPL` 苹果、`NVDA` 英伟达、`TSLA` 特斯拉、指数 `.IXIC`），自动归入 `美股` 分组；
- **添加主流币**：输入币对名称（如 `BTCUSDT`、`ETHUSDT`、`SOLUSDT`），自动归入 `Binance` 分组；
- **添加链上新币**：粘贴 EVM 合约地址（`0x...` 42位）或 Solana Mint 地址（32~44位），自动归入 `Alpha` 分组并拉取池子行情。

### 2. 批量多选与拖拽重排

- **单只拖拽**：在侧边栏鼠标按住任意资产直接拖拽上下移动；
- **多选批量拖拽**：按住 `Ctrl` / `Cmd` 键多选，或按住 `Shift` 键范围连选多个标的，鼠标直接批量拖拽至目标位置；
- **一键置顶**：鼠标悬停在资产上，点击 `🔝` 图标即可瞬间将其置顶到当前分组第一位。

### 3. 配置到价预警与波动监控

- **侧边栏快捷配置**：鼠标悬停在标的上，点击 **`🔔`** 按钮，按照向导输入目标价或涨跌幅；设置完成后标的行将常驻显示 `🔔` 标志；
- **集中管理预警矩阵**：点击看板顶部 **`⚙️`** 打开设置中心，切换至「⚡ 到价预警」标签页，批量统一微调目标价与启用开关。

### 4. 查看丰富详情悬停气泡与一键复制

将鼠标悬停在任意自选标的上，即可弹出专业详情气泡并支持一键快捷复制：

- **深度盘口指标 (A股)**：换手率、市盈率 (TTM)、市净率 (PB)、当日振幅、流通市值、总市值、涨跌停限制价、量比与分时均价；
- **基础行情**：今开、昨收、当日最高价、最低价；成交量、成交额（股票/指数）；
- **链上指标**：全网流动性池深度、24H成交额与市值 FDV（DEX 资产）；
- **一键复制标的代码 / 合约地址**：悬停卡片内置 `[📋 复制]` 交互链接，或在标的右键上下文菜单中选择「复制标的代码」，告别手工抄写。
