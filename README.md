## 🌟 为什么选择 MarketLens？

作为程序员，在工作专注编码时，经常需要兼顾自选资产（基金、股票、指数、加密代币、矿币、链上新币）的盘面异动。频繁切换桌面炒股炒币软件不仅打断工作心流，而且容易被旁人察觉。

**MarketLens** 将全市场行情与效率预警深度融合进 VS Code 编辑器中：

- 🌲 **六合一全能行情**：场内ETF/基金、A股、港股、美股、加密货币 (Binance主流币 & SafeTrade矿币)、Alpha 链上新币一站式聚合，告别多软件频繁切换；
- ⛏️ **主流加密与矿币全覆盖**：默认输入 `BTCUSDT` 走币安，支持输入 `safetrade:prlusdt` 或粘贴 SafeTrade 链接直接监控未上架主流所的优质矿币（免 API Key、自动代理兼容）；
- 📡 **数据全链路溯源**：鼠标悬停在任意标的上，卡片底部清晰显示数据源（`SafeTrade` / `Binance` / `DexScreener` / `腾讯财经`）及秒级更新时效；
- 🎯 **交易日今日打新日历**：A股新股、可转债、港股IPO申购窗口智能提醒，一键回车复制申购信息，单日防打扰；
- ⚡ **市场全景行情中心**：一键呼出 6 Tab 全景中心（大盘 9 区间分布直方图、行业板块/龙头/ETF/加密 Squarified 矩形树图、全球宏观与大宗外汇、恐慌贪婪仪表盘）；
- 🚀 **智能异动监控与炸板预警**：支持 A 股涨停封板/炸板秒级感知、滑动窗口短时急拉/跳水监控及 DEX 5m 突变突击预警；
- ⚡ **到价预警与波动监控**：突破上限、跌破下限、单日暴涨暴跌实时提醒，无需时刻盯盘，专注写代码；
- 🔍 **中文/拼音智能联想搜索**：无需死记数字代码，直接输入股票中文名（如“茅台”）或拼音缩写（如“GZMT”）实时联想添加；
- 🖱️ **多选批量拖拽与多维排序**：支持多选批量拖拽重排，支持按涨跌幅、现价、拼音升降序快速排序；
- 🏷️ **自定义别名与精细化轮播**：支持为任意标的设置展示简称/伪装名，单个标的独立控制是否参与状态栏轮播；
- 🕶️ **极致专注与安全隐秘**：配备老板键一键隐藏、终端日志伪装摸鱼、颜色脱敏模式、休市自动折叠与节流；
- 📊 **状态栏无缝轮播**：底部状态栏按需滚动行情，支持各板块与单标的独立开关精细控制及紧凑模式；
- 🧹 **活跃集修剪与极低内存占用**：自动回收死缓存与内存对齐机制，常态增量堆内存仅数兆（Heap Used 稳定 < 15MB~25MB），持久挂机无泄漏；
- 🛡️ **网络安全**：境内正规源直连，Web3 接口强制走本地代理，杜绝公司网关留痕。

## ✨ 核心功能与特性

### 1. 🌐 全市场资产六合一覆盖

- 📈 **基金板块 (场内 ETF / 联接指数基金)**：
    - 专设置顶基金分组与配置中心专属面板；
    - 支持科创50ETF、创业板ETF、纳指ETF、黄金ETF等场内基金与指数代码智能解析；
    - 同样支持休市停刷、状态栏轮播与独立排序记忆。
- 🇨🇳 **A股市场 (沪深京)**：
    - 直连境内正规金融源，零延迟实时拉取；
    - 覆盖上证、深证、北交所全市场股票与各大指数（如上证指数、沪深300、ETF等）；
    - 智能交易时段判定：仅在工作日交易时段轮询，收盘及周末自动休眠节流。
- 🇭🇰 **港股市场 (HK Stocks)**：
    - 覆盖恒生指数、腾讯控股、美团、阿里巴巴、小米等核心资产；
    - 支持标准 5 位代码识别（如 `00700`、`03690`），多币种港币（`HK$`）专属结算展示。
- 🇺🇸 **美股市场 (US Stocks)**：
    - 覆盖纳斯达克、标普500、道琼斯全市场标的及指数；
    - 苹果 (`AAPL`)、英伟达 (`NVDA`)、特斯拉 (`TSLA`)、微软 (`MSFT`)、纳指 (`.IXIC`) 实时追踪；
    - 智能识别北京时间夜间交易时段与盘后展示。
- 🪙 **加密货币板块 (Binance 主流币 & SafeTrade 矿币)**：
    - **主流代币全覆盖**：覆盖 BTC、ETH、SOL、BNB、DOGE 等币安主流币种，24 小时全天候无间断拉取最新行情与波动；
    - **SafeTrade 矿币扩展**：支持直接添加未在币安上架的优质矿币（如输入 `safetrade:prlusdt` 或粘贴交易对网址），自动通过 SafeTrade 公开接口并行抓取，免 API Key、自动复用本地代理探活；
    - **老用户平滑升级**：开箱默认分组名为「加密货币」，老用户启动插件时自动平滑升级为新命名，标的与排序完好保留，并终生保留自主改名权限。
- 🦄 **Alpha 链上 DEX 聚合 (全链新币)**：
    - 集成 DexScreener 全球去中心化交易所聚合行情；
    - 支持 Solana、BSC、Base、以太坊、Arbitrum 等主流公链；
    - 只需粘贴代币合约地址，即可秒级识别代币名称、价格、24h 涨跌及流动性池深度。

### 2. 🎯 交易日今日打新与申购日历（A股新股 / 可转债 / 港股IPO）

专为国内与港股投资者打造的打新神器，无需每天手动去同花顺或券商软件翻日历：

- **智能时段无感检测**：
    - 仅在交易日申购窗口期（北京时间 09:15 ~ 15:00）启动自动检测；
    - 自动聚合东方财富官方 A 股新股、A 股可转债配售与港股 IPO 招股日程；
    - **单日防轰炸机制**：全天最多主动提醒一次，若今日无标的申购则全天静默，绝不重复弹窗打扰；
- **回车一键复制申购代码**：
    - 点击通知右下角「查看详情」，在窗口正顶端弹出常驻 QuickPick 快捷面板；
    - 详情面板清晰列出标的类型、证券代码、**网上申购专用代码**、发行价格、申购上限及关联正股；
    - 键盘回车或鼠标点击任意标的，**自动将标准申购文本复制到系统剪贴板**，方便切到券商 APP 或同花顺一键粘贴下单；
- **摸鱼与老板键一票否决**：
    - 处于老板键隐蔽或专注打码期间，打新提醒全局自动静默，杜绝敏感弹窗自曝。

### 3. ⚡ 价格阈值与剧烈波动预警监控系统（极度刚需）

写代码时无需一直盯盘，当标的突破关键阻力位、跌破止损位或出现暴跌剧烈异动时，系统及时精准提醒：

- **灵活丰富的预警与异动规则**：
    - **`A 股涨停封板与炸板提醒`**：现价触及涨停价推送封板提醒，涨停打开回落时秒级预警防利润回吐；
    - **`盘中短时快速急拉/跳水`**：滑动窗口捕捉 3 分钟内超幅异动（默认 ±3%，支持自定义）；
    - **`DEX 链上代币 5m 突变感知`**：原生接通链上 5 分钟涨跌幅，大幅异动秒级提醒；
    - **`突破上限预警 (高于目标价)`**：现价大于等于目标值时提醒（如茅台突破 1800、BTC 突破 75000）；
    - **`跌破下限预警 (低于目标价)`**：现价小于等于目标值时提醒（如茅台跌破 1500、SOL 跌破 110）；
    - **`单日剧烈波动预警 (涨跌幅突破)`**：日内涨跌幅绝对值超过阈值百分比时提醒（如单日涨跌超 10%）；
- **双通道智能提醒方式**：
    - **VS Code 右下角轻量通知**：轻量弹窗浮窗提示，支持快速关闭与操作；
    - **状态栏闪烁高亮**：底部状态栏静默高亮变色切换，绝不打扰代码思路；
    - **双通道协同**：通知弹窗与状态栏同时提醒。
- **15分钟防轰炸冷却机制（可自定义）**：
    - 同一标的触发报警后，内存自动拦截进入冷却静音期（默认 15 分钟，支持在设置中自定义 1~1440 分钟），防止关键价位反复小幅拉锯引发连续弹窗轰炸。
- **老板键一票否决静音守卫**：
    - 当通过老板键隐藏看板时，预警评估引擎自动启动全局静默守卫，一票否决全部弹窗通知，彻底杜绝摸鱼露馅风险。
- **标的常驻持久化 `🔔` 标记与气泡预览**：
    - 只要标的配置了有效的预警规则，侧边栏标的行右侧将**常驻显示 `🔔` 图标**；
    - 鼠标悬停在标的上即可在卡片气泡中实时预览当前生效的具体预警阈值。
- **图形化集中监控矩阵**：
    - 在 Webview 设置面板「⚡ 到价预警」中提供全局监控矩阵，支持集中查看全部板块自选标的、直接在表格中调整目标价数值与独立监控开关；
    - 侧边栏与设置面板 **0ms 双向实时同频**，在侧边栏添加、删除或拖拽标的，设置面板无需关闭重开即刻同步。

- **真实涨跌停池直连**：直连东财专题池，精准获取当天沪深京两市真实封板与跌停家数；
- **原生 Squarified 矩形树图 (Treemap)**：零第三方依赖自研几何排布算法，按成交额/市值权重与涨跌幅色彩自适应渲染 A 股 80+ 行业板块、港股核心龙头、美股科技七巨头 (Magnificent 7)、热门 ETF 及主流加密资产热力图；
- **全球宏观与大宗外汇**：道琼斯、纳斯达克、标普500、日经225、恒生指数、上证指数，纽约黄金、WTI 原油、离岸人民币实时汇率；
- **加密货币宏观情绪**：Alternative.me 恐慌与贪婪指数（0~100）半圆仪表盘与过去 7 天对比，币安 24h 现货领涨/领跌 Top 5 排行榜；
- **轻量独立 HUD**：按需懒加载并提供 6 个市场 Tab 骨架，关闭浮窗立即停止轮询，0 后台常驻开销；老板键联动自动关闭，兼顾隐私。

### 5. 💾 自选标的与配置一键导出与导入恢复（换机与分享神器）

- **📤 一键导出备份 (JSON)**：
    - 将当前全部自选标的（含基金/A股/港股/美股/Binance/Alpha）、自定义备注名、排序位置、到价预警规则及全局偏好设置导出为标准 JSON 备份文件；

    - 支持 VS Code 命令面板（`MarketLens: 导出配置备份 (JSON)...` / `MarketLens: 导入配置恢复 (JSON)...`）与图形化设置中心按钮两种操作方式。

### 6. 🔀 灵活的标的置顶、分组多维排序与别名管理（支持多选批量重排）

- **多选批量拖拽排序**：
    - 支持按住键盘 `Shift`（连续多选）或 `Ctrl` / `Cmd`（离散多选）鼠标点击选中 3~5 个或任意数量标的；
    - 鼠标拖拽一次性批量移动至目标位置，保持所选标的的相对顺序；
    - **同组边界严格隔离**：内置板块边界守卫，严格限制仅在当前分组内调整顺序，彻底杜绝跨板块误拖拽；
    - **单次原子化写入**：一次操作仅触发一次磁盘持久化，消除高频 I/O 冲突。
- **分组多维排序模式 (`sortGroup`)**：
    - 点击自选分组标题右侧的排序按钮，即可随时切换 6 种排序方式：**默认自定义拖拽序、按日内涨幅降序 (`+9.9% → -2.1%`)、按涨幅升序、按现价降序、按现价升序、按名称拼音字母序**；
    - 每个分组独立记忆排序模式，满足不同市场的盯盘习惯。
- **标的自定义展示简称 / 别名 (`setAlias`)**：
    - 右键点击标的菜单选择「设置标的展示简称 / 别名...」，即可为任意资产设置个性化别名；
    - 同步应用于左侧自选树、悬停卡片与底部状态栏（例如：将冗长晦涩的合约代币改名为简短中文，或在办公室将个股改名为“模块架构”辅助摸鱼防窥）。
- **休市自动折叠非交易分组 (`autoCollapseClosedGroups`)**：
    - A股、港股、美股在收盘及周末休市期间，侧边栏对应分组会自动收起折叠，开盘时自动展开，自动聚焦当前正在交易的活跃资产（如夜间自动收起 A 股聚焦美股与 7×24 Crypto）。
- **一键置顶标的**：右键点击标的或通过命令选择 **🔝 置顶**，即可瞬间将核心关注标的移动至当前分组第一行；
- **快速设置预警与删除**：悬停点击 **`🔔` 预警** 按钮呼出设置向导；点击 **`🗑️` 删除** 图标安全移除单只标的；
- **一键清空自选标的**：在设置中心支持一键将所有默认预设标的置空，保留板块结构，方便从零自由建立属于自己的自选库；
- **一键恢复出厂预设**：随时一键重置回系统初始预设资产库，并同步清空重置所有价格预警规则。

### 8. 📈 全球核心大盘指数一键快捷导入（秒级开箱即用）

- **一键导入全球核心基准指数**：

1. **绝对零凭证与零数据上传**：
    - 插件**不需要任何 API Key、Token 或用户账号密码**；
    - 绝不收集、记录或上传用户的代码、工作区、设备指纹或自选标的列表，所有自选资产仅安全保存在本地 VS Code 的 `settings.json` 中。
2. **强制代理底层物理阻断（杜绝直连降级）**：
    - 当为特定板块（如 Binance、Alpha）开启【强制代理】后，网络层会严格仅向本地回环代理端口（如 `http://127.0.0.1:10808` 或 `7890`）投递数据包；

    - **公司网关留痕防御**：目标域名解析（DNS）与 TLS 握手均在本地代理软件及代理节点内部完成，企业防火墙和网络审计设备只能观察到 VS Code 进程与本地环回地址（`127.0.0.1`）之间的通信，无法捕获到 `binance.com` 等敏感域名的 SNI 握手特征。
3. **一键代理自动探测与自适应探测池**：
    - 设置中心提供 `⚡ 探测代理` 按钮，自动识别本机常见代理端口（如 Clash `7890`/`7897`、v2rayN `10808`/`10809`、sing-box `2080` 等），一键配置零门槛；
    - 具备 30 秒全局探测冷却与熔断保护，代理离线时绝不引发请求风暴。
4. **交易时段休眠节流**：
    - 基金、A股、港股、美股在非交易时段及周末全自动停发轮询请求，进一步规避不必要的网络发包特征。
